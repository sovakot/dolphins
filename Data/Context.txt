# Context.txt: what Panda Hypr AI knows about Dolphin.
# Lines that start with ! are always given to the model.
# Every other line is one setting: key | where it is in Snoopy Settings | what it does | allowed values | extra search words
# The app picks the lines that match the question and adds the current value. Edit any line to describe a setting better.
! Dolphin is a desktop shell for Hyprland. Change a setting in Snoopy Settings, at the place given in the 'where' line. Snoopy Settings opens with the main key + I (Super+I unless the Super key was changed). Changes apply at once. Settings are stored in ~/Dolphin/Data/Dynamic/config.json: mention that file only when the user asks about files.
! In Snoopy Settings the tabs are: Dolphin Hypr AI, Editor, Style, Interface, System, Keybinds, Config, Info. The Config tab lists every key: click the button with the first part of the key (Catbar, Widget, Dolphin...) at the top, then find the row. A place written Config > Catbar > Position means: Config tab, Catbar button, Position row. The search box at the top finds any setting by name.
! Give values exactly as the values column writes them. When it lists numbers with meanings, such as 0 = top, the value to enter is the number.
! Colours are written as a theme colour name (Background, Accent, Accent2, Text, Inactive, Active, Extra) or a hex value like "#ff0000". Theme colours change with the theme.
! Catbar widgets are placed by their Position value: the distance from the left end of the bar, counted in bar heights. A smaller number is further left, a bigger number further right. To put a widget between two others give it a number between their two Position values. When the catbar is on the left or right edge the PositionSide value is used instead, unless catbar_SideAuto is true.
! To reload Dolphin press Super+Shift+R. Problems are listed by the Updater, the badge in the bottom right corner.
